# Comunicacion de parties y command channels

## Estado

Documento exploratorio. La necesidad de voz y su implementacion no estan aprobadas.

## Propuesta registrada

Considerar un sistema de voz integrado con salas por party y un command channel para eventos grandes. Los lideres del command channel podrian hablar a todas las parties o a grupos determinados de forma configurable.

## Preguntas Pendientes para el Equipo

- ¿La voz sera una funcion propia o una integracion externa?
- ¿Que permisos tienen lideres, asistentes y miembros?
- ¿Como se gestionan moderacion, reportes, bloqueo y privacidad?
- ¿Como se crean, destruyen y persisten las salas?
- ¿Que impacto tiene la voz en Web, escritorio, ancho de banda y accesibilidad?
- ¿El sistema debe funcionar tambien con chat de texto y party inquiry?
